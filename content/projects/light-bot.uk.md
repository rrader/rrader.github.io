У нашому новому будинку і мені, і сусідам було дуже корисно знати, коли точно є світло, а коли його немає. Оскільки в квартирі роутер та домашній сервер заживлені від резервного живлення і не вимикаються, я створив просте та надійне інженерне рішення: воно всередині квартири пінгує пристрої, підключені напряму до міської мережі 220V, та оперативно сповіщає всіх сусідів через Telegram-канал.

**Light-Bot** — це комплексне open-source рішення для моніторингу електромережі, підрахунку тривалості відключень, надання захищеного REST API та автоматичної публікації звітів у Telegram.

* **Вихідний код:** [github.com/rrader/light-bot](https://github.com/rrader/light-bot)
* **Стек технологій:** Python 3, Flask, Telegram Bot API, Docker, Systemd, Shell scripting

## 1. Архітектура системи

Головна проблема полягає в тому, що роутер та домашній сервер заживлені від резерву і не втрачають живлення при блекауті.

Рішення реалізовано за дворівневою схемою:

```
[ Пристрій без резерву ] (кондиціонер / реле в розетці 220V)
          │
          │ (ICMP Ping / Heartbeat)
          ▼
[ Локальний роутер / Зонд ] ──(HTTPS + Токен)──► [ Віддалений хмарний VPS ]
                                                          │
                        ┌─────────────────────────────────┴─────────────────────────────────┐
                        ▼                                                                   ▼
              [ Telegram-канал ]                                                  [ Home Assistant ]
              (Живі звіти та статистика)                                          (Автоматизації / REST Sensor)
```

1. **Локальний крайовий зонд (`monitor.sh`):**
   - Працює на роутері або міні-сервері, заживленому від станції резервного живлення.
   - Періодично пінгує одну або кілька фіксованих IP-адрес пристроїв у локальній підмережі, підключених напряму до міської мережі 220V (наприклад, внутрішній блок кондиціонера чи розумну розетку).
   - Має захист від помилкових спрацьовувань (debouncing): статус змінюється лише після кількох підтверджених невдалих спроб поспіль.
   - При зміні стану надсилає підписаний HTTPS-запит із токеном на віддалений VPS.

2. **Хмарний сервер (`main.py`):**
   - Працює на зовнішньому VPS у дата-центрі, незалежному від відключень у місті.
   - Містить багатопотоковий Flask REST API, захищений авторизаційним Bearer-токеном.
   - Зберігає стан у файлі (`power_status.txt`), щоб не втрачати історію при перезапуску сервісу.

## 2. Сповіщення в Telegram та розрахунок інтервалів

При переході стану мережі між `ON` та `OFF` бот формує структуроване повідомлення у закріплений Telegram-канал:

* **Тривалість знеструмлення:** при поверненні світла бот автоматично вираховує, скільки саме тривало відключення (наприклад, `4 год 12 хв`), і публікує це в повідомленні.
* **Тривалість роботи зі світлом:** при зникненні електроенергії фіксується, скільки годин оселя була безперервно заживлена перед новим вимкненням.
* **Стійкість до збоїв:** механізм повторних спроб надсилання гарантує, що ліміти Telegram API чи короткочасні збої зв'язку не призведуть до втрати важливого статусу.

## 3. Безпечний REST API та інтеграція з розумним будинком

Крім публікації в месенджер, Light-Bot надає REST-ендпоінти для інтеграцій:

* `GET /health` — перевірка працездатності для систем аптайм-моніторингу.
* `GET /power-status` — повертає поточний статус, таймстемп та тривалість:
  ```json
  {
    "status": "on",
    "timestamp": 1720100784,
    "formatted_time": "2026-07-04 16:26:24",
    "duration_minutes": 252
  }
  ```
* `POST /power-status` — оновлення стану від локального скрипта за заголовком `Authorization: Bearer <API_TOKEN>`.

### Інтеграція з Home Assistant
Через REST API система легко підключається до Home Assistant на Synology NAS як бінарний сенсор:

```yaml
binary_sensor:
  - platform: rest
    name: "Статус світла в оселі"
    resource: "https://your-server.com/power-status"
    method: GET
    headers:
      Authorization: !secret light_bot_token
      User-Agent: "HomeAssistant/2026.9"
    device_class: power
    value_template: "{{ value_json.status == 'on' }}"
    scan_interval: 15
```

Цей сенсор є ключовим тригером для енергозберігаючих сценаріїв: негайно вимикає бойлер та важкі нагрівачі при відключенні 220V, та плавно поновлює роботу клімату й заряджання станції після стабілізації напруги.
