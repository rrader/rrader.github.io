Вінтажне індустріальне обладнання минулих десятиліть має неповторну тактильну привабливість. Важкий сталевий антивандальний корпус, механічний дзвін монет при падінні у скарбничку, масивна телефонна слухавка на броньованому шнурі та металева матрична клавіатура дарують відчуття, які не здатні відтворити сучасні сенсорні смартфони.

**zk_phone** — це апаратний пет-проєкт глибокої модернізації (retrofitting): перетворення автентичного монетоприймального вуличного таксофона на інтерактивний цифровий пристрій під керуванням Raspberry Pi та власного софту на Python.

* **Вихідний код:** [github.com/rrader/zk_phone](https://github.com/rrader/zk_phone)
* **Апаратна частина:** Монетний таксофон, Raspberry Pi, матрична клавіатура, текстовий LCD (HD44780), важіль слухавки (Hook switch)

![Автентичний таксофон, модернізований за допомогою Raspberry Pi](/images/zk_phone/phone1.jpg)

## 1. Апаратна реверс-інженерія та підключення

Оригінальний таксофон був створений для роботи в суворих громадських умовах. Щоб вдихнути в нього друге життя, ключові електромеханічні вузли було досліджено та підключено до контактів GPIO на Raspberry Pi:

1. **Важіль трубки (Hook Switch):**
   - Фіксує стан: чи лежить трубка на базі, чи її підняли для дзвінка.
   - Підключений як цифровий вхід із підтягувальними резисторами та програмним антибрязканням контактів (debounce).
   - Слугує головним тригером системи: підняття трубки вмикає підсвітку дисплея та ініціалізує режим набору номера.

2. **Металева матрична клавіатура:**
   - Індустріальна клавіатура працює за схемою мультиплексованої матриці рядків і стовпців.
   - Опитується в циклі подій GPIO в реальному часі.
   - Натискання клавіш супроводжуються звуковим фідбеком і заносяться в буфер набору.

3. **Символьний LCD-дисплей (HD44780):**
   - Встановлений за оглядовим склом інформаційного вікна для виведення набраних цифр, статусу та системної діагностики.
   - Підтримує секретні сервісні коди: наприклад, комбінація `*1#` виводить на екран поточні IP-адреси Raspberry Pi у локальній мережі.

4. **Монетний механізм:**
   - Механічний тракт монетоприймача із мікроперемикачами для фіксації номіналу та зарахування монет.

## 2. Архітектура програмного забезпечення

Програма написана на Python та спроєктована навколо скінченного автомата (Finite State Machine, FSM) у модулі `zk_phone/app.py`:

```
           ┌──────────────────────┐
           │   Очікування (Поклали)│
           └──────────┬───────────┘
                      │ Підняли трубку
                      ▼
           ┌──────────────────────┐
           │ Активний режим набору│ ◄──── Події матричної клавіатури
           └──────────┬───────────┘
                      │
           ┌──────────┴───────────┐
           ▼                      ▼
    [ Сервісні коди ]      [ Телефонний сценарій ]
      (напр. *1# IP)
```

### Логіка станів:
* **Стан `HandsetPut`:** активується, щойно користувач підіймає важку трубку. Очищає буфер екрана, вітає користувача повідомленням на LCD та чекає на введення цифр.
* **Керування буфером:** кожна натиснута кнопка додається до буфера та миттєво відображається на дисплеї.
* **Сервісні функції:** спеціальні комбінації дозволяють обслуговувати систему (перевірити стан мережі, перезавантажити ОС, протестувати соленоїд скидання монет).

## 3. Чим особливий такий хардварний хакінг

Модернізація раритетних залізок — це один із найприємніших напрямів DIY:
* Збереження неповторного ретро-футуристичного дизайну та міцності, якої більше не роблять.
* Поєднання брутальної механіки минулого століття з сучасним кодом на Python та Linux.
* Створення унікального артефакту для домашнього кабінету чи хакерспейсу, який викликає щире захоплення у кожного гостя.
