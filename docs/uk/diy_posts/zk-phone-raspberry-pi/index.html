zk_phone — програмування таксофона на базі Raspberry Pi

🌐 Інші мови:🇬🇧 English

zk_phone — це пет-проєкт програмування вуличного таксофона на базі Raspberry Pi та софту на Python.

  • Вихідний код: github.com/rrader/zk_phone
  • Апаратна частина: таксофон, Raspberry Pi, символьний LCD-дисплей (HD44780), матрична клавіатура, герконовий перемикач важеля слухавки (reed switch)

1. Як влаштована логіка

Програма написана на Python і побудована на базі простого автомата станів (State Machine) у модулі zk_phone/app.py.

Стан 1: Трубка лежить на важелі (HandsetPut)

  • На дисплеї світиться привітання: Hello!.
  • Працюють сервісні коди з клавіатури:
    • *1# — виводить на LCD поточні локальні IP-адреси Raspberry Pi.
    • *7# — підтягує через внутрішнє API та виводить на екран версію релізу Zakupki.Prom.

Стан 2: Трубку підняли (HandsetRaised)

  • При піднятті слухавки спрацьовує перемикач важеля (reed switch).
  • Голосовий синтезатор у слухавці вимовляє: “Hello. Type station number and hash”.
  • На дисплеї з’являється підказка: Station and #.
  • Користувач набирає номер радіостанції та решітку:
    • 1# — Radio ROKS (http://www.radioroks.ua/RadioROKS.m3u)
    • 2# — Lounge FM (http://cast.loungefm.com.ua:8000/loungefm.m3u)
  • У фоновому потоці запускається mplayer, і обране онлайн-радіо транслюється прямо в динамік телефонної слухавки, а на LCD відображається Playing <номер>.

Стан 3: Трубку поклали назад

  • Щойно слухавка опускається на важіль, відтворення аудіо негайно зупиняється (player.kill()).
  • На дисплеї виводиться повідомлення Thank you!, після чого таксофон повертається в режим очікування.
